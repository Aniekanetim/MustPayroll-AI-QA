# Fixed build: UI functional suite

These six cases test the payroll operator's browser journey at http://127.0.0.1:4276. TC03 and TC04 belong to the separate [API suite](../API%20testing/api-test-suite.md). Every date below is in 2026. Both builds use the same expectations.

Each case starts with fresh isolated test records. The [execution guide](executed_functional_test_cases/README.md) explains automated setup and the one-shot failure controls; those technical setup calls do not replace the browser actions below. Payment runs always simulate the selected Tuesday at 09:00 UTC. A payroll dataset is a set of test records, not a feature the operator manages.
